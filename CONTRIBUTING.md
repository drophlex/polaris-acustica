# Cómo proponer cambios a Polaris Acústica

Este proyecto es mantenido por **Polaris Sound Lab** (Mérida, Yucatán, México). El código tiene un único responsable y **no se aceptan cambios directos**: todo pasa por él.

## ¿Tienes una idea o quieres modificarlo?
1. Abre una [propuesta de cambio](../../issues/new?template=propuesta.yml) y cuéntame qué te gustaría mejorar y por qué.
2. También puedes escribirme a **drophlex@gmail.com** o a @polaris.sound.lab en Instagram.
3. Si la idea me convence, te doy acceso (colaborador) para que trabajes el código en una rama y abras un Pull Request. Yo lo reviso y decido si se integra.

## Reglas
- Nadie puede modificar la rama `main` salvo el responsable.
- Los Pull Requests de personas sin acceso no se integran sin una propuesta previa aprobada.
- Ver [LICENSE](LICENSE): el código no es de uso libre sin permiso.
